# 🍅 Pomodoro Timer — SwiftUI App

A simple and minimal **Pomodoro Timer** built with SwiftUI to help you focus effectively using the 25-minute Pomodoro technique.

---


---

## ✨ Features
- 25-minute countdown timer  
- Start and Reset controls  
- Clean SwiftUI layout with gradient styling  
- Auto-stop when leaving the view  

---

## 🛠️ Built With
- **Swift**  
- **SwiftUI**  
- **Xcode**
